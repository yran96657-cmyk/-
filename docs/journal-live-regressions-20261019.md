# 期刊新版实测与输出修复（2026-10-19）

基于 `7c6d896c0c9d60ec128ae7007d0a637d619297c9` 复测在线 DEMO，并在本分支验证修复。真实稿件、作者资料、凭据、PDF 和逐页截图仅保存在私有工作区；仓库只加入可公开的合成回归样例。

## 复现与修复

| 问题 | 实际后果 | 本分支行为 |
| --- | --- | --- |
| 默认西文字体缺少正文中的 μ、θ、δ | 单位 μmol 变成 mol，2θ 丢失 θ，离子价态丢失 δ | 保留原始 Unicode；当前字体有字形时继续使用，否则使用显式文本字体补字；缺字仍作为阻断报告 |
| 导入的复合正体标点包裹比较符号，长公式不能断行 | 实测公式超宽 16.59152 pt | 测量宽度后在安全的外层运算符处断行；保护括号、绝对值、分数与上下标，逗号保留在上一行末尾；不缩小或裁剪公式 |
| 密集行内公式段落可断行但 TeX 不采用 | 实测段落超宽 35.28754 pt | 仅对含公式的期刊段落启用紧急断行计算，保持正文和公式字号 |
| 窄表格第一英文单词不能正常断词 | `Dispersion/%` 表头超宽 5.6877 pt | 允许英文开头单元格的首词正常断词，不改源文本或列宽 |
| 字体选择与服务器环境不一致 | 使用缺失的字体提交整篇任务后才失败；换中文字体仍保留轻字重 | 启动时使用实际 XeLaTeX/fontspec 检查固定字体配置，缺失配置在分配作业前拒绝；模板界面明确提供常规/轻字重；尊重 `SHUYE_FONTSET` 默认值，不自动替换显式字体 |
| 下载后仅有简短错误总数 | 产品经理难以找到具体缺字、页面和对象 | 浏览器显示当前修订的阻断/警告、物理页、候选源对象及编译器证据；JSON 同样提供结构化诊断供 AI 使用 |

编译器行号和字符匹配给出的是**候选来源**。同一字在多处出现、同一 gather 环境包含多个公式时，报告保留全部候选，不能将其解释为精确的字形坐标。字体清单只验证字体可用性，不证明全文字形覆盖或字体使用许可。
