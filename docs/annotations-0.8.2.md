# 注释与参考文献视觉校正

此轮修复针对 `journal.annotations.fontSet="founder-sample"` 的 PDF 排版。
它保留工程中的原始文字、作者、日期、文献排序与编号。

- 首面脚注使用开明式标点间距、固定标签宽度与悬挂缩进。通信作者在显示层使用星号；其他原稿符号保存在源文档中，普通脚注不受影响。
- 参考文献类型标记使用全角字形和光学边距；文献编号不重排。URL、DOI 与普通数学方括号不作为文献类型标记转换。
- 英文参考文献使用字宽测量、英文断词和逐行填充。含独立数学对象、注音或无法准确测量的字样使用原有排版器。
- 支持针对校样人工校正 PDF 断行，避免用修改正文或替换作者大小写来凑出样本行尾。

## MCP 校正指定参考文献

`apply_typesetting.styles[].patch.referenceBreaks` 与 `update_block` 均接受：

```json
{
  "sourceText": "[1] AUTHOR. A journal article. 2026, 8: 1-9.",
  "breaks": [{"offset": 18, "hyphen": true}]
}
```

`offset` 是**完整原文（包括编号）中的 UTF-16 偏移**；`hyphen=true` 仅允许在英文单词内部显示行尾连字符。它不会向 `text` 写入连字符或换行符。`sourceText` 必须来自当前组件，禁止猜测或改写。

使用 `apply_typesetting` 时先 `dryRun:true`，再以同修订、同参数及返回的 `previewHash` 提交。设置 `referenceBreaks:null` 清除。编辑原文会自动丢弃过期断行；排版工具会拒绝向其他原文套用断行。改变字号、栏宽后仍需重新检查 PDF，校正位置不是排版质量保证。

仅复制确认为同一条、内容可对应的样本断行。来源版本的作者、年份、卷期、页码、文献数不同，必须列为内容差异，不能借排版校正改写。字符顺序核对须考虑 PDF 光学悬挂：按字符 x 坐标重排会把 `sets[J]` 错读为 `set[sJ]`。

## 验收要求

本轮验收包含真实 HTTP MCP 的预览、提交、重载、PDF 导出及源内容不变检查；同时检查字体、字号、行距、编号、缩进、栏式和渲染图。参数检查不替代视觉对照。具体交付记录在最终验收报告中。
