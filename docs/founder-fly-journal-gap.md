# 中文学术期刊：方正飞翔对照与产品决策

调研日期：2026-10-15。评审基线：`a52fa035b8e1592ef21f2f77109d88f68398d367`。首个交付场景：含公式、图表、双栏的中文学术期刊。

当前可以继续推进**有人负责校对的单篇试产**，还不能承诺无人值守的工业级交付。本次代码改动优先消除静默损失、错误放行和无反馈的 AI 修改；后续投资应以客户验收样本和返工工时为依据。

## 对照对象与证据等级

官方印刷产品页当前列出 **9.0-1794，2026-07-07 更新**。详细操作依据为官网公开的 **8.0 印刷版手册，314 个 PDF 页面**；下文同时给出印刷页码和 PDF 页码，不能把旧版手册称为 9.0 实机结果。官方产品页声明支持 Word 的 MathType/Omath 公式、批处理与中文禁排设置；这些是能力说明，本次没有在飞翔安装实例中验证速度、保真率或同稿分页。[官方产品与版本说明](https://www.founderfx.cn/product/1012.jhtml)

方正书版、飞翔印刷版、飞翔数字版与鸿云学术出版平台应分开评估。鸿云官方说明采用 XML 主源、单篇生产与整期组刊，并输出 PDF、RichHTML、H5、XML；这给我们的学术期刊业务提供流程参照，不能直接当作飞翔单机版能力。[鸿云 XML 数字化生产系统](https://www.journal.founderss.cn/pages/publish.html)

## 从手册提炼的生产能力

以下能力均来自 [方正飞翔 8.0 印刷版官方手册](https://www.founderfx.cn/resources/support/%E6%96%B9%E6%AD%A3%E9%A3%9E%E7%BF%948.0%E5%8D%B0%E5%88%B7%E7%89%88%E8%AF%B4%E6%98%8E%E4%B9%A6.pdf)，是简要归纳；右列是对本项目的工程判断。

| 能力与定位（印刷页 / PDF 页） | 本项目需要承担的验收责任 |
| --- | --- |
| 禁排设置与复合字体：39 / 55 | 中英文、数字、标点及公式用字应分别锁定；不能只检查字号 |
| 预检定位缺字、缺图、溢出与颜色问题：44 / 60 | AI 必须获得问题位置；未覆盖的检查须明确列出 |
| PDML/XML、Word 输出和打包：57 / 73 | 主源、资产及交付副本需绑定版本；不能只保存一份 PDF |
| 锚定盒子的智能延后：163 / 179 | 图、题注、首次引用与栏/页之间需要约束，不是仅有图块 |
| 可重复应用的表格框架：202 / 218 | 期刊模板须包含表头、表线、对齐、跨页和表注规则 |
| 脚注分栏、表内标记脚注：264–267 / 280–283 | 必须保留引用与注释内容；表内脚注也不能伪装成正文字符串 |
| 整书预检与打包：277 / 293 | 收尾要覆盖全篇/整期、资产清单、字体信息和报告 |

手册提及未压缩 XML 可供程序生成、修改、提取和导入。这是值得继续验证的接入点，但**尚未证实公开的无界面 CLI、SDK、MCP、无人值守授权或稳定 schema 契约**。也不能从“支持 XML”推导出“可直接当作服务端排版引擎”。后续应在用户自行安装的具体版本上测试 XML 往返与授权边界。

另外，手册描述了表内标记脚注后续手工处理，不能把它概括为“任意复杂表注自动完美处理”。对照应比较同一输入、同一字体、同一模板的实际成品，不以厂商功能清单代替验收。

## 首个付费产品的收敛建议

建议先限定一种期刊模板和明确的输入子集，按“单篇排版 + 人工校对 + 可追溯交付包”试产。复杂化学式、OLE、跨页大合并表、特殊竖排等在报价前识别并约定人工处理，不能等到交付时才发现。

按以下顺序推进；这是产品建议，不是未经验证的工期承诺：

1. **内容保真门**：扩充客户同意使用的匿名黄金样本，公式、图表、题注、脚注、引用逐项对应；导入错误必须归零或有明确处置证据。
2. **模板门**：首面信息、双栏、标题禁则、公式编号、三线表与续表、图注、参考文献，用目标期刊编辑认可的成品逐页对照。
3. **AI 闭环门**：源对象 ID → 页面坐标 → 约束诊断 → 候选 → 审核 → 原子提交；现有 revision/候选校样是基础，尚不是自动收敛系统。
4. **交付门**：不可变源文件、资产、模板版本、字体/工具版本、校样及报告、编辑批准与印厂回执分别归档，恢复后再输出仍可核对。
5. **经营验证门**：记录每篇人工分钟数、返工轮次、一次验收率、渲染失败率和总直接成本，再决定报价与扩张。

每篇贡献毛利可按“实收金额 − 排版人工 − 校对人工 − 计算/许可/交付直接成本 − 返工成本”核算。当前没有客户报价、工时和续费数据，不能声称一定盈利或推导市场价格。扩模板、扩稿型之前，先证明一个模板的质量和单位经济性成立。

## 飞翔实机对照实验（待执行）

记录用户安装的产品、版本、字体及授权方式；双方使用同一组原创样本。至少包含：四类定界符、行内与表内公式、表注、TIFF 与失效链接、跨页合并表、图注锚定、修改标题后重排、缺字/溢出定位，以及 XML 导出—重新导入。测量内容差异、逐页差异、人工修复分钟数、可编程入口和恢复能力。

只有该对照完成，才适合对外承诺具体能力对等。官方页面的兼容、效率与质量表述均不作为本项目的测试成绩。
