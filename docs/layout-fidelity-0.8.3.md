# 期刊版式与源内容保留

0.8.3 增加完整的参考刊式字体方案和角色缩进控制，修复双栏脚注规则造成的分页溢出。字体必须由部署方自行安装并取得使用授权，仓库不包含商业字体。

## MCP 控制

`apply_typesetting` 沿用 `dryRun → previewHash → 提交` 流程。新增参数通过同一文档校验和版本历史保存：

- `layout.fontSet: "founder-sample"`：书宋正文、黑体标题、楷体作者、仿宋摘要；西文另选 `journal.latinFont: "times"`。先检查字体清单，缺失时阻止提交。
- `journal.roleStyles[role].fontFamily`：`serif / sans / kai / fangsong`。
- `leftIndentMm / rightIndentMm / firstLineIndentPt`：角色左右缩进、首行缩进；字号和行距沿用 TeX pt。页首 `spaceBefore` 保留指定留白。
- `cjkTrackingPt / latinTrackingPercent`：角色中文字距和西文字距；西文字距为 em 的百分比，`journal.latinTrackingPercent` 可设置正文默认值。
- `journal.headerFontSize / headerLeading`：双语页眉字号和行距。通用书名页眉属于显式覆盖；使用期刊页眉时恢复通用占位值。
- `journal.excludedParagraphs`：用户确认的模板残留，包含 `blockId / sourceText / reason`。原段不删除，打印覆盖率另列排除记录；原文改变、注释、公式和锚点段落均拒绝排除。
- `journal.excludedImages`：用户确认的小型独立装饰图残留，包含 `blockId / sourceSrc / reason`。严格绑定原图，不支持图表题注、单元格图和矢量内容。
- `journal.paragraphJoins`：`[{blockIds:[...],separator:""或" "}]`，仅联排连续同角色的文字段落。保留每个源段和行内公式的 PDF 定位，Word 导出保留可编辑文字及公式。

组件 `journalStyle` 的优先级高于期刊角色样式。更换模板时应检查并有意清除旧覆盖，而非仅检查模板参数。`get_typesetting_context` 隐去排除图像的二进制内容，完整绑定数据须读取工程。

## 修正

脚注分隔线必须具有零净高度；现在自定义线宽和线后间距同步调整补偿量，避免双栏首面纵向溢出。方正仿宋的粗体标签明确采用黑体，不再触发不可用字形替代。参考刊式上下标使用实测比例；摘要内的文献引用不再被正文引用字号放大。分类号行不再把原稿开头空格扩成大间距。摘要、关键词、分类信息标签独立采用黑体／西文粗体，不被正文常规字重覆盖。中西文交界增加可伸缩间距，防止带字距的混排长行轻微超宽。

## 验收口径

成品尺寸依据 PDF TrimBox，而非含出血的 MediaBox。检查源内容摘要、字体嵌入、字形和行距、栏式、实际源对象位置及逐页视觉。编译成功、部署前后输出一致，均不等于与出版样本逐页一致。

原稿与出版样本的内容版本差异、缺失原图、引文与编号差异需要单独记录；不能通过改写作者、日期、正文或文献编号来掩盖。私有实稿、测试 PDF、源图及服务器凭据不随代码发布。
