# 学术排版工作流

书页面向需要处理中文学术稿件的编辑。桌面工作区保留中央纸面、左侧结构和右侧属性；学术期刊默认打开 Agent 任务，人工操作与 Agent 执行共用同一份结构化工程。完整契约见 [Agent 工作流](agent-workflow.md)。

![项目库：合成演示项目](images/journal-workflow-library.png)

## 从稿件到可检查的校样

1. 在项目库直接点击“导入 Word”选择 DOC/DOCX，无需先创建示例工程；编辑器顶栏也可导入。缺少的图体通过“补入图”逐项绑定。也可新建“学术期刊”；模板含中英文题名、作者、单位、摘要、关键词、编号公式、三线表及参考文献；模板内容全部为演示占位。
2. 在纸面编辑正文，或在属性中调整版式与组件。浏览器对首面角色使用专用字体层级；它仍是结构编辑预览，实际首面通栏、分页和锚点关系以 PDF 为准。
3. 点击“整理为学术期刊”，由 Agent 按 170×240 毫米、双栏、栏距 6 毫米、正文 8 pt 的规则方案识别并整理文章，预检后保存并生成校样。无需先手工配置全部首面角色，也无需本机模型。它是一种明确的期刊版型，不代表所有刊物的规范；使用“自定义版式”提交其他参数要求。当前已满足的参数不出现在差异中。
4. 生成校样后查看页数、数学区、字体嵌入与对象映射。当前修订已有校样时，顶栏显示“查看校样”，复用现有结果；改稿后显示“更新校样”，保存并生成新结果。打开 PDF 核对真实版面，按需下载 PDF 或报告。下载前再次检查源修订，读取期间继续修改也会阻止交付旧版本。
5. 报告中的“补全刊物信息”“定位并编辑”直接进入相应字段。补图后点击“保存并重新检查”继续任务；已经生成过校样的稿件会保留人工版式，只重新检查当前修订。
6. 选中表格后可直接“编辑表格”；含单元格换行的表格禁用按行拆分的文本替换，避免破坏原始行列。删除组件可撤销，撤销会恢复原组件选择。批注使用页面内多行输入，未解决批注进入校样报告。
7. 没有后续修改时，可撤销整份 AI 提案并创建恢复修订；有人工修改时，旧提案和直接撤销会被拒绝，防止覆盖新内容。无变化的 Ctrl/⌘S 不创建新修订。

![桌面工作区：Agent 完成排版后呈现修改差异与校样](images/agent-workflow-result.png)

任务操作固定在结果区底部；可停止并接管、继续任务或整次撤销。重复取回同一修订的校样不再启动编译；同一页面的重复生成动作共用一个进行中的请求。一次任务授权覆盖连续执行；遇到歧义或质量问题会停止并交接。

## AI 的职责

Agent 负责整个校样流程。标准整理使用可检查的规则；自定义版式使用已配置的本机模型把意图转为十种受限参数。服务端先检查 schema、几何和源修订，再依据任务授权应用；修改前后差异保留在任务中。正文、公式和图片不发送给内置模型，只有用户主动输入的要求、数字参数与结构统计参与推理。模型未就绪、响应不完整、断线和非法建议都应可见且不写入文稿。人负责源稿疑点、图件质量和最终审阅，未解决批注在任务中持续可见。

更完整的外部 agent 可以通过 MCP 读取结构、逐项编辑与查看实际校样坐标：

| 阶段 | 入口 | 检查点 |
| --- | --- | --- |
| 发现 | `list_projects`、`get_project_context` | 工程、修订、角色缺口、分页章节与能力路线 |
| 定位 | `list_components`、`get_document_schema` | 稳定组件 ID、公式来源、单位与引用 |
| 试排 | `apply_changes` + `dryRun:true` | 原子验证，无持久写入 |
| 应用 | `apply_changes` + `expectedRevision` | 拒绝过期修订和非法组合 |
| 校样 | `get_journal_capabilities`、`start_journal_proof` | 运行环境可用、任务绑定源版本 |
| 复核 | `get_journal_proof_page`、检查报告、PDF | 实际对象位置与逐页人工验收 |
| 恢复 | `restore_version` | 以新修订恢复，保留记录 |

`get_project_context` 省略图片数据、导入报告和长正文；章节按 offset/limit 分页，角色缺口和未绑定题注仅为结构提示。它不判断数学语义、视觉质量或印刷批准。`get_project_status` 只查用户隔离的元数据，编辑器先检查修订变化再获取完整文稿；大图片工程不再每次轮询传输全文。云端项目草稿与本地文稿使用 IndexedDB，旧 localStorage 草稿只在成功迁移后移除。打字时延迟 400 ms 合并写入，离开页面前立即尝试保存。显式保存前保留当前快照，保存成功只清理匹配的草稿；新输入或冲突草稿不会被一起删除。浏览器清理站点数据仍会删除本地草稿，应使用“下载备份”保留工程文件；打开备份时通过页面内确认替换当前文稿，可撤销。

## 整期与交付边界

整期编排独立保存选稿、顺序与源修订。环境未启用整期引擎时，可以继续编排和保存，生成按钮明确禁用；单篇 XeLaTeX 校样是另一条独立能力。历史源稿更新后，需要重新绑定文章版本并生成校样。

本流程用于专业学术编辑的辅助工作。自动检查通过不等于可发印；全文、公式语义、图表准确性、每页版面、字体许可和印厂条件仍需专业验收。模型能力与真实稿件覆盖率应通过目标语料单独评估，不能由少量合成演示推算。
